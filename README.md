# 🎨 EasyDraw Application

![Java](https://img.shields.io/badge/Language-Java-orange?style=for-the-badge&logo=java)
![JavaFX](https://img.shields.io/badge/Framework-JavaFX-blue?style=for-the-badge)
![Year](https://img.shields.io/badge/Project_Year-2024-purple?style=for-the-badge)

A desktop-based interactive drawing application built using **Java** and **JavaFX GUI toolkit**[cite: 1]. Developed as an academic programming final project in 2024[cite: 1].

---

##  Features & Highlights

- **Interactive Canvas:** Freehand drawing with custom brush sizes and colors[cite: 1].
- **Drawing Tools:** Support for line, rectangle, circle, and star shapes[cite: 1].
- **Eraser Mode:** Quick canvas cleanup using white color overriding[cite: 1].
- **UI Customization:** ColorPicker integration and smooth FadeTransitions for logo entry[cite: 1].



## Tech Stack

- **Language:** Java[cite: 1]
- **GUI Framework:** JavaFX[cite: 1]
- **Layout Managers:** `BorderPane`, `VBox`, `HBox`, `StackPane`[cite: 1]
- **Architecture:** Event-Driven Programming with `GraphicsContext` & `MouseEvent` handlers[cite: 1]
